# 재개발 지역 길고양이 구조 의무화 특별법 국민동의청원

정적 사이트입니다. 빌드 과정 없음. `index.html` 하나로 동작합니다.

## 서명 숫자 업데이트 (매일 하는 일)

1. 이 저장소에서 `count.json` 파일을 누릅니다
2. 오른쪽 위 연필(✏️) 아이콘을 누릅니다
3. 숫자만 고칩니다
4. 아래 초록색 **Commit changes** 버튼을 누릅니다
5. 1분쯤 뒤 사이트에 자동 반영됩니다

```json
{ "count": 5846, "updated": "2026-08-09" }
```

- `count` : 현재 서명 인원
- `updated` : 갱신한 날짜 (화면에는 안 나오고 기록용)

숫자를 못 불러와도 사이트는 깨지지 않고, 마지막으로 알려진 값으로 표시됩니다.

## 파일 구조

```
index.html        페이지 전체 (HTML·CSS·JS 한 파일)
count.json        서명 숫자
images/og.jpg     카카오톡·인스타 링크 미리보기 이미지
images/icon-*.png 파비콘
images/web/       페이지에 쓰는 사진 (압축본)
```

사진 원본은 용량이 커서 이 저장소에 없습니다. 별도 보관하세요.
